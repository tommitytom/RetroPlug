# Modular graph engine, Phase B0: the parity baseline - implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for
> tracking.

**Goal:** Record today's engine, bit for bit, in committed hashes that `pnpm test:native` holds every later
change to, so Phase B can move the engine onto the graph and prove it changed nothing.

**Architecture:** Per [docs/modular-graph-phase-b0-design.md](modular-graph-phase-b0-design.md). A
determinism switch powers cores on in a fixed state; a `renderBlocks` driver call renders scripted host
blocks as the plugin does; a rig over the app's own control plane drives 153 cases through the stores; a
group runner records `test-native/parity/baseline/<group>.json` and checks against it, refusing to record
silence, an ignored stimulus, or a case that depends on the cases before it. Three engine and store bugs
are fixed first so the baseline holds correct behaviour.

**Tech stack:** C++20 (the engine, CMake), TypeScript on txiki (`retroplug-host`), the repo's TAP harness,
esbuild via the native test runner, Catch2 for the SMS test.

**Provenance:** every code block below was built and run before this plan was written, on the scratch
branch `proto/b0` in this worktree (one prototype commit per concern), with GCC 13.3 on linux-x64. Each
code block is pulled verbatim from a prototype commit, and every expected count and failure message is what
that run printed. The recording tasks end by diffing the recorded baseline against the prototype's: the
code is the same, so the hashes must be.

// RETROPLUG_DETERMINISTIC=1 (set by the test runner for every parity file) powers each core on in a
// fixed state: SameBoy's GB_random() returns 0, and Mesen NES RAM powers on as all zeros. Without it
// two boots of the same ROM in one process disagree about work RAM, because SameBoy's generator advances
// between them and Mesen draws fresh random bytes.
import { test, expect } from "../../testing/harness";
import { bootSession } from "../../src/bootSession";

declare const __REPO_RESOURCES_DIR__: string;

const session = bootSession();

function bootAndReadRam(load: () => number | null): Uint8Array {
  const id = load();
  expect(typeof id, "the system builds").toBe("number");
  session.audio.renderAudio(100);
  const ram = session.project.systems.readRam(id as number);
  expect(ram != null, "work RAM is published").toBeTruthy();
  session.project.systems.removeSystem(id as number);
  return ram as Uint8Array;
}

// Counted rather than compared whole, so a failure says how far apart the boots are instead of printing
// both RAM images.
function bytesDiffering(a: Uint8Array, b: Uint8Array): number {
  let n = Math.abs(a.length - b.length);
  for (let i = 0; i < Math.min(a.length, b.length); i++) if (a[i] !== b[i]) n++;
  return n;
}

test("two SameBoy boots power on with identical work RAM", () => {
  const a = bootAndReadRam(() => session.project.systems.loadMgb());
  const b = bootAndReadRam(() => session.project.systems.loadMgb());
  expect(a.length).toBeGreaterThan(0);
  expect(bytesDiffering(a, b)).toBe(0);
});

test("two Mesen NES boots power on with identical work RAM", () => {
  const nes = __REPO_RESOURCES_DIR__ + "/roms/bliptoaster.nes";
  const a = bootAndReadRam(() => session.project.systems.addSystem(nes));
  const b = bootAndReadRam(() => session.project.systems.addSystem(nes));
  expect(a.length).toBeGreaterThan(0);
  expect(bytesDiffering(a, b)).toBe(0);
});
```

#pragma once

// RETROPLUG_DETERMINISTIC=1 powers every core on in a fixed state instead of a random one: SameBoy's
// GB_random() returns 0 (it otherwise seeds from time(NULL), filling WRAM / HRAM / OAM / wave RAM at
// reset), and Mesen NES RAM powers on as all zeros (NesConfig defaults to Random). Real hardware powers
// on unpredictably, which is what the app keeps; only the parity harness (test-native/parity and
// tools/run-reaper-parity.sh) sets this, so a recorded hash cannot depend on the wall clock.

#include <cstdlib>
#include <cstring>

namespace rp {

// Read once per process: the SameBoy flag it drives is a process-global static anyway.
inline bool deterministic() {
    static const bool on = [] {
        const char* v = std::getenv("RETROPLUG_DETERMINISTIC");
        return v != nullptr && std::strcmp(v, "1") == 0;
    }();
    return on;
}

} // namespace rp
```

```ts
// renderBlocks: the parity suite's capture call. It renders a scripted run of host blocks the way the
// plugin renders each one, so these check that it is the SAME render the rest of the suite already
// trusts (renderAudio), that it places lanes, and that it refuses what a DAW never sends.
import { test, expect } from "../../testing/harness";
import { bootSession } from "../../src/bootSession";

const session = bootSession();
const { project, audio } = session;

const CHORD = [
  [0x90, 60, 100],
  [0x91, 64, 100],
  [0x92, 67, 100],
];

function rms(a: Float32Array, from = 0, to = a.length): number {
  let s = 0;
  for (let i = from; i < to; i++) s += a[i] * a[i];
  return to > from ? Math.sqrt(s / (to - from)) : 0;
}

test("at 2 outputs in 1024-frame blocks it is renderAudio, bit for bit", () => {
  const frames = Math.floor((500 * audio.sampleRate()) / 1000); // what renderAudio(500) renders
  project.newProject();
  project.systems.loadMgb();
  for (const m of CHORD) audio.stageMidiIn(m);
  const mixed = audio.renderAudio(500);

  project.newProject();
  project.systems.loadMgb();
  const blocks = [];
  for (let at = 0; at < frames; at += 1024) blocks.push({ frames: Math.min(1024, frames - at) });
  blocks[0] = { ...blocks[0], midi: CHORD.map((bytes) => ({ frame: 0, bytes })) };
  const { lanes } = audio.renderBlocks(2, blocks);

  expect(lanes.length).toBe(2);
  expect(lanes[0].length).toBe(frames);
  expect(mixed.length).toBe(frames * 2);
  let differing = 0;
  for (let i = 0; i < frames; i++) {
    if (Object.is(mixed[2 * i], lanes[0][i]) === false) differing++;
    if (Object.is(mixed[2 * i + 1], lanes[1][i]) === false) differing++;
  }
  expect(differing).toBe(0);
  expect(rms(lanes[0])).toBeGreaterThan(0.001); // and it is not two silences agreeing
});

test("one system under Stereo routing lands on the first pair of an 8-lane host", () => {
  project.newProject();
  project.systems.loadMgb();
  const { lanes } = audio.renderBlocks(8, [
    { frames: 512, midi: CHORD.map((bytes) => ({ frame: 100, bytes })) },
    ...Array.from({ length: 30 }, () => ({ frames: 512 })),
  ]);
  expect(lanes.length).toBe(8);
  expect(rms(lanes[0])).toBeGreaterThan(0.001);
  expect(rms(lanes[1])).toBeGreaterThan(0.001);
  for (let c = 2; c < 8; c++) expect(rms(lanes[c]), `lane ${c}`).toBe(0);
});

test("it refuses what a host never sends", () => {
  project.newProject();
  expect(() => audio.renderBlocks(3 as 2, [{ frames: 64 }])).toThrow("outputs must be 2, 4, 6 or 8");
  expect(() => audio.renderBlocks(2, [{ frames: 0 }])).toThrow("block 0: frames must be 1..8192");
  expect(() => audio.renderBlocks(2, [{ frames: 64 }, { frames: 8193 }])).toThrow("block 1: frames must be 1..8192");
  expect(() => audio.renderBlocks(2, [{ frames: 64, midi: [{ frame: 64, bytes: [0x90, 60, 1] }] }])).toThrow(
    "is outside a 64-frame block",
  );
  expect(() =>

constexpr std::uint32_t kMaxRenderBlockFrames = 8192;

// Why renderBlocks refuses `req`, or empty. Checked whole before anything renders, so a refused request
// leaves the Engine exactly as it was.
std::string renderBlocksRefusal(const RpcRenderBlocksRequest& req) {
    if (req.outputs < 2 || req.outputs > 8 || req.outputs % 2 != 0) return "outputs must be 2, 4, 6 or 8";
    for (std::size_t b = 0; b < req.blocks.size(); ++b) {
        const RpcRenderBlock& blk = req.blocks[b];
        const std::string at = "block " + std::to_string(b) + ": ";
        if (blk.frames == 0 || blk.frames > kMaxRenderBlockFrames)
            return at + "frames must be 1.." + std::to_string(kMaxRenderBlockFrames);
        std::uint32_t last = 0;
        for (const RpcBlockMidi& m : blk.midi) {
            if (m.bytes.empty()) return at + "a MIDI message is empty";
            if (m.frame >= blk.frames)
                return at + "MIDI at frame " + std::to_string(m.frame) + " is outside a " + std::to_string(blk.frames) + "-frame block";
            // A DAW delivers events frame-sorted, so the order today's engine gives unsorted input is
            // never part of a baseline; ties keep their list order.
            if (m.frame < last)
                return at + "MIDI frames go backwards (" + std::to_string(m.frame) + " after " + std::to_string(last) + ")";
            last = m.frame;
        }
        for (const auto& c : blk.controller)
            if (c.empty() || c.size() > 4) return at + "a controller message must be 1..4 bytes";
        if (blk.bpm && !(*blk.bpm > 0.0)) return at + "bpm must be positive";
    }
    return {};
}

RpcRenderBlocksResult EngineRpcService::renderBlocks(RpcRenderBlocksRequest req) {
    RpcRenderBlocksResult result;
    // This thread calls processBlock itself, which only the Engine's owning thread may do.
    if (invoker_.audioThreadOwns()) {
        result.error = "the background audio thread is running";
        return result;
    }
    result.error = renderBlocksRefusal(req);
    if (!result.error.empty()) return result;

    std::uint64_t total = 0;
    for (const RpcRenderBlock& b : req.blocks) total += b.frames;
    // Whole-run planar lanes; each block renders straight into its own slice of them.
    std::vector<std::vector<float>> lanes(req.outputs, std::vector<float>(total));
    std::vector<float*> outs(req.outputs);

    std::uint64_t at = 0;
    for (std::uint32_t b = 0; b < req.blocks.size(); ++b) {
        RpcRenderBlock& blk = req.blocks[b];
        // PluginDSP::run's order: host MIDI staged at its frames, then the control plane's queued edits,
        // then transport, then the block itself.
        for (RpcBlockMidi& m : blk.midi) engine_.stageMidi(m.frame, std::move(m.bytes));
        for (auto& c : blk.controller) engine_.stageControllerMidi(std::move(c));
        invoker_.drainInto(engine_);
        if (blk.bpm) engine_.setBpm(*blk.bpm);
        if (blk.playing) engine_.setTransport(*blk.playing);
        if (blk.ppq) engine_.setPpq(*blk.ppq);
        for (std::uint32_t c = 0; c < req.outputs; ++c) outs[c] = lanes[c].data() + at;
        engine_.processBlock(blk.frames, outs.data(), req.outputs);
        for (const auto& mo : engine_.midiOut()) {
            RpcBlockMidiOut o;
            o.block  = b;
            o.system = mo.system;
            o.frame  = mo.frame;
            const auto* p = reinterpret_cast<const std::byte*>(mo.data.data());
            o.data.assign(p, p + mo.data.size());
            result.midiOut.push_back(std::move(o));
        }
        engine_.clearMidiOut();
        at += blk.frames;
    }

    result.lanes.reserve(req.outputs);
    for (const auto& l : lanes) {
        const auto* p = reinterpret_cast<const std::byte*>(l.data());
        result.lanes.emplace_back(p, p + l.size() * sizeof(float));
    }
    return result;
}

// What a parity baseline records about a case, and how two records are compared. Pure: no host calls,
// so the comparator can be proven on its own (comparator.test.ts).

/** One run of blocks: its length, and one "fnv rms" string per lane. */
export interface SegmentDigest {
  frames: number;
  lanes: string[];
}

/** A whole case: its segments in order, the kernel's MIDI out, and at the end each battery system's SRAM
 *  and every system's work RAM, keyed by project slot. Work RAM is stable only because the parity suite
 *  powers cores on in a fixed state (util/Determinism.hpp); it catches state a stimulus changed without
 *  making a sound. */
export interface CaseDigest {
  segments: SegmentDigest[];
  midiOut: { count: number; fnv: string };
  sram: Record<string, { length: number; fnv: string }>;
  ram: Record<string, { length: number; fnv: string }>;
}

/** One MIDI-out message as recorded: the block index counts from the start of the case, and the system
 *  is its project slot rather than its id (ids differ between a case run in its group and run alone). */
export interface MidiOutEntry {
  block: number;
  slot: number;
  frame: number;
  data: Uint8Array;
}

const FNV_OFFSET = 0x811c9dc5;
const FNV_PRIME = 0x01000193;

/** FNV-1a (32-bit) over `bytes`, continuing from `h`. */
export function fnv1a(bytes: Uint8Array, h = FNV_OFFSET): number {
  for (let i = 0; i < bytes.length; i++) h = Math.imul(h ^ bytes[i], FNV_PRIME) >>> 0;
  return h;
}

export const hex8 = (n: number): string => (n >>> 0).toString(16).padStart(8, "0");

/** RMS to 4 significant figures, "0" for exact silence. Computed from the very bits that are hashed, so
 *  it is as stable as the hash; it is there so a re-recorded baseline reads ("lane 3 went silent"). */
export function rms4(lane: Float32Array, from: number, to: number): string {
  let s = 0;
  for (let i = from; i < to; i++) s += lane[i] * lane[i];
  if (s === 0) return "0";
  return Math.sqrt(s / (to - from)).toPrecision(4);
}

/** "fnv rms" for frames [from, to) of one lane: the hash covers the float bit patterns. */
export function laneDigest(lane: Float32Array, from: number, to: number): string {
  const bytes = new Uint8Array(lane.buffer, lane.byteOffset + from * 4, (to - from) * 4);
  return `${hex8(fnv1a(bytes))} ${rms4(lane, from, to)}`;
}

export function midiDigest(entries: MidiOutEntry[]): { count: number; fnv: string } {
  let h = FNV_OFFSET;
  const word = new Uint8Array(4);
  const view = new DataView(word.buffer);
  for (const e of entries) {
    for (const n of [e.block, e.slot, e.frame, e.data.length]) {
      view.setUint32(0, n, true);
      h = fnv1a(word, h);
    }
    h = fnv1a(e.data, h);
  }
  return { count: entries.length, fnv: hex8(h) };
}

export function bytesDigest(bytes: Uint8Array): { length: number; fnv: string } {
  return { length: bytes.length, fnv: hex8(fnv1a(bytes)) };
}

/** Is `lane` audible in the case after its first segment? The first is where systems boot, and a boot
 *  chime is not what a case means by "this lane sounds". A one-segment case is judged on that segment. */
export function laneSounds(d: CaseDigest, lane: number): boolean {
  const judged = d.segments.length > 1 ? d.segments.slice(1) : d.segments;
  return judged.some((s) => s.lanes[lane] !== undefined && !s.lanes[lane].endsWith(" 0"));
}

const describe = (lane: string): string => {
  const [fnv, rms] = lane.split(" ");
  return `${fnv} (rms ${rms})`;
};

/** Why `actual` is not `expected`, or [] when they match. Audio names the FIRST segment and lane that
 *  differ, which is where to look; `audio: false` compares only MIDI out, SRAM and work RAM (a platform
 *  whose float output cannot be held to the baseline's). */
export function compareDigests(expected: CaseDigest, actual: CaseDigest, opts: { audio: boolean }): string[] {
  const problems: string[] = [];
  if (opts.audio) problems.push(...compareAudio(expected, actual));
  if (expected.midiOut.count !== actual.midiOut.count || expected.midiOut.fnv !== actual.midiOut.fnv)
    problems.push(
      `MIDI out: expected ${expected.midiOut.count} message(s) hashing ${expected.midiOut.fnv}, ` +
        `got ${actual.midiOut.count} hashing ${actual.midiOut.fnv}`,
    );
  for (const [label, key] of [["SRAM", "sram"], ["work RAM", "ram"]] as const) {
    const slots = [...new Set([...Object.keys(expected[key]), ...Object.keys(actual[key])])].sort();
    for (const slot of slots) {
      const e = expected[key][slot];
      const a = actual[key][slot];
      if (!e || !a) problems.push(`${label} slot ${slot}: ${e ? "missing" : "unexpected"}`);
      else if (e.length !== a.length || e.fnv !== a.fnv)
        problems.push(`${label} slot ${slot}: expected ${e.length} bytes hashing ${e.fnv}, got ${a.length} hashing ${a.fnv}`);
    }
  }
  return problems;
}

/** The audio half of compareDigests: the first segment and lane that differ, or []. */
export function compareAudio(expected: CaseDigest, actual: CaseDigest): string[] {
  if (expected.segments.length !== actual.segments.length)
    return [`expected ${expected.segments.length} segment(s), got ${actual.segments.length}`];
  let start = 0;
  for (let s = 0; s < expected.segments.length; s++) {
    const e = expected.segments[s];
    const a = actual.segments[s];
    if (e.frames !== a.frames || e.lanes.length !== a.lanes.length)
      return [`segment ${s}: expected ${e.frames} frames x ${e.lanes.length} lanes, got ${a.frames} x ${a.lanes.length}`];
    for (let l = 0; l < e.lanes.length; l++)
      if (e.lanes[l] !== a.lanes[l])
        return [
          `segment ${s} (frames ${start}..${start + e.frames}), lane ${l}: ` +
            `expected ${describe(e.lanes[l])}, got ${describe(a.lanes[l])}`,
        ];
    start += e.frames;
  }
  return [];
}

/** JSON with every object's keys sorted, one value per line: a re-record diffs line by line. */
export function stableJson(v: unknown): string {
  const sort = (x: unknown): unknown =>
    Array.isArray(x)
      ? x.map(sort)
      : x !== null && typeof x === "object"
        ? Object.fromEntries(Object.keys(x as object).sort().map((k) => [k, sort((x as Record<string, unknown>)[k])]))
        : x;
  return JSON.stringify(sort(v), null, 1) + "\n";
}

// share), reset to a known state before each case, and a render call that plays a segment through
// renderBlocks. Cases drive it through the stores, as the UI does, so a case survives Phase B: B2 deletes

import type { RenderBlock } from "../../src/audioDriver";
import { laneDigest, type MidiOutEntry, type SegmentDigest } from "./digest";

declare const __CONFIG_DIR__: string;
declare const __DSP_KERNEL_BUNDLE__: string;

/** One run of host blocks. Events are placed by ABSOLUTE frame within the segment and land in the block
 *  that contains them; transport changes apply at the start of the block containing their frame. */
export interface Segment {
  /** Block sizes, in order. */
  blocks: number[];
  midi?: { at: number; bytes: number[] }[];
  controller?: { at: number; bytes: number[] }[];
  transport?: { at: number; playing?: boolean; bpm?: number; ppq?: number }[];
  /** A store edit made after this segment renders and before the next one does. */
  after?: (rig: Rig) => void;
}

/** `total` frames in blocks of `size` (the last one short). */
export function even(total: number, size: number): number[] {
  const out: number[] = [];
  for (let at = 0; at < total; at += size) out.push(Math.min(size, total - at));
  return out;
}

/** `total` frames in blocks cycling through `sizes` (the last one short): a DAW's irregular blocks. */
export function cycle(total: number, sizes: number[]): number[] {
  const out: number[] = [];
  for (let at = 0, i = 0; at < total; i++) {
    const n = Math.min(sizes[i % sizes.length], total - at);
    out.push(n);
    at += n;
  }
  return out;
}

const ROM_DIR = `${__CONFIG_DIR__}/parity-roms`;
const swapExt = (path: string, ext: string): string => path.replace(/\.[^./]+$/, "") + ext;

export class Rig {
  readonly session: Session = bootSession();
  /** Blocks rendered since the last reset: the MIDI-out block index counts from the start of the case. */
  private blockBase = 0;

  get project() {
    return this.session.project;
  }
  get audio() {
    return this.session.audio;
  }

  /** Back to a known state: no systems, default project settings, a freshly loaded kernel, the transport
   *  stopped at ppq 0 and 120 bpm, `sampleRate`, nothing pending, and no ROM copies left from the last
   *  case (a leftover "-2.sav" would be adopted by the next duplicate). */
  reset(sampleRate: number): void {
    this.project.newProject();
    for (const name of this.session.backend.listDir(ROM_DIR))
      if (!name.endsWith("/")) this.session.backend.deleteFile(`${ROM_DIR}/${name}`);
    const { dsp, audio } = this.session;
    if (!dsp.loadKernel(dsp.compileScript(__DSP_KERNEL_BUNDLE__)!)) throw new Error("the kernel did not reload");
    audio.setTransport(false);
    audio.setPpq(0);
    audio.setBpm(120);
    if (!audio.setSampleRate(sampleRate)) throw new Error(`setSampleRate(${sampleRate}) refused: is a system still live?`);
    audio.drainMidiOut();
    if (audio.systemCount() !== 0) throw new Error(`${audio.systemCount()} system(s) survived the reset`);
    this.blockBase = 0;
  }

  /** A fresh copy of `src` (and of the battery beside it, if any) in this file's temp dir, so a case
   *  never writes a committed .sav and always starts from the same battery. `prefix` names the copy apart
   *  from others of the same ROM: a second instance of one path gets the "-2.sav" battery slot, which a
   *  case cannot seed in advance, so two systems that each need a battery each need their own copy. */
  rom(src: string, prefix = ""): string {
    const backend = this.session.backend;
    const dst = `${ROM_DIR}/${prefix}${src.slice(src.lastIndexOf("/") + 1)}`;
    const bytes = backend.readFile(src);
    if (!bytes) throw new Error(`cannot read ${src}`);
    backend.writeFile(dst, bytes);
    for (const ext of [".sav", ".srm"]) {
      const battery = backend.readFile(swapExt(src, ext));
      if (battery) backend.writeFile(swapExt(dst, ext), battery);
    }
    return dst;
  }

  /** Add a ROM (copied first) as a new system; throws if it does not build. */
  add(src: string): number {
    const id = this.project.systems.addSystem(this.rom(src));
    if (id == null) throw new Error(`${src} did not build`);
    return id;
  }

  /** The id of the system in project slot `slot`. */
  id(slot: number): number {
    const v = this.project.systems.view()[slot];
    if (!v) throw new Error(`no system in slot ${slot}`);
    return v.id;
  }

  /** Render one segment at `outputs` lanes; returns its digest, its MIDI out, and the lanes themselves. */
  render(outputs: 2 | 4 | 6 | 8, seg: Segment): { digest: SegmentDigest; midiOut: MidiOutEntry[]; lanes: Float32Array[] } {
    const starts: number[] = [];
    let total = 0;
    const blocks: RenderBlock[] = seg.blocks.map((frames) => {
      starts.push(total);
      total += frames;
      return { frames };
    });
    const blockAt = (at: number): number => {
      if (at < 0 || at >= total) throw new Error(`an event at frame ${at} is outside a ${total}-frame segment`);
      let b = 0;
      while (b + 1 < starts.length && starts[b + 1] <= at) b++;
      return b;
    };
    for (const m of [...(seg.midi ?? [])].sort((x, y) => x.at - y.at)) {
      const b = blockAt(m.at);
      (blocks[b].midi ??= []).push({ frame: m.at - starts[b], bytes: m.bytes });
    }
    for (const c of seg.controller ?? []) (blocks[blockAt(c.at)].controller ??= []).push(c.bytes);
    for (const t of seg.transport ?? []) {
      const blk = blocks[blockAt(t.at)];
      if (t.playing !== undefined) blk.playing = t.playing;
      if (t.bpm !== undefined) blk.bpm = t.bpm;
      if (t.ppq !== undefined) blk.ppq = t.ppq;
    }

    const slotOf = new Map(this.project.systems.view().map((v, i) => [v.id, i]));
    const r = this.audio.renderBlocks(outputs, blocks);
    const midiOut = r.midiOut.map((m) => ({
      block: this.blockBase + m.block,
      slot: slotOf.get(m.system) ?? -1,
      frame: m.frame,
      data: m.data,
    }));
    this.blockBase += blocks.length;
    return { digest: { frames: total, lanes: r.lanes.map((l) => laneDigest(l, 0, total)) }, midiOut, lanes: r.lanes };
  }
}

export interface ParityCase {
  name: string;

  needs?: string[];
  /** Hz; default 48000. */
  sampleRate?: number;
  outputs: 2 | 4 | 6 | 8;
  /** Lanes that must sound after the first (boot) segment: a recording refuses to write silence for them.
   *  Empty for a case whose recorded behaviour IS silence, which says why in a comment. */

  segments: Segment[];
}

const text = new TextDecoder();

/** Run one case from a reset, returning its digest and (when asked) its lanes per segment. `unstimulated`
 *  drops every segment's MIDI, controller traffic and transport, for the check that they matter. */
function runCase(
  rig: Rig,
  c: ParityCase,
  keepLanes: boolean,
  unstimulated = false,
): { digest: CaseDigest; lanes: Float32Array[][]; midi: MidiOutEntry[] } {
  rig.reset(c.sampleRate ?? 48000);
  c.setup(rig);
  const segments = [];
  const lanes: Float32Array[][] = [];
  const midi: MidiOutEntry[] = [];
  for (const seg of c.segments) {
    const r = rig.render(c.outputs, unstimulated ? { blocks: seg.blocks } : seg);
    segments.push(r.digest);
    midi.push(...r.midiOut);
    if (keepLanes) lanes.push(r.lanes);
    seg.after?.(rig);
  }
  const sram: CaseDigest["sram"] = {};
  const ram: CaseDigest["ram"] = {};
  rig.project.systems.view().forEach((v, slot) => {
    const b = v.battery ? rig.project.systems.readSram(v.id) : null;
    if (b) sram[String(slot)] = bytesDigest(b);
    const r = rig.project.systems.readRam(v.id);
    if (r) ram[String(slot)] = bytesDigest(r);
  });
  return { digest: { segments, midiOut: midiDigest(midi), sram, ram }, lanes, midi };
}

/** A mono 32-bit float WAV. */
function floatWav(lane: Float32Array, sampleRate: number): Uint8Array {
  const out = new Uint8Array(44 + lane.length * 4);
  const v = new DataView(out.buffer);
  const tag = (at: number, s: string) => s.split("").forEach((ch, i) => v.setUint8(at + i, ch.charCodeAt(0)));
  tag(0, "RIFF");
  v.setUint32(4, 36 + lane.length * 4, true);
  tag(8, "WAVE");
  tag(12, "fmt ");
  v.setUint32(16, 16, true);
  v.setUint16(20, 3, true); // IEEE float
  v.setUint16(22, 1, true);
  v.setUint32(24, sampleRate, true);
  v.setUint32(28, sampleRate * 4, true);
  v.setUint16(32, 4, true);
  v.setUint16(34, 32, true);
  tag(36, "data");
  v.setUint32(40, lane.length * 4, true);
  out.set(new Uint8Array(lane.buffer, lane.byteOffset, lane.length * 4), 44);
  return out;
}

function dump(rig: Rig, group: string, c: ParityCase, lanes: Float32Array[][], midi: MidiOutEntry[]): string {
  const dir = `${DUMP}/${group}/${c.name}`;
  const backend = rig.session.backend;
  const outputs = lanes[0]?.length ?? 0;
  for (let l = 0; l < outputs; l++) {
    const whole = new Float32Array(lanes.reduce((n, seg) => n + seg[l].length, 0));
    let at = 0;
    for (const seg of lanes) {
      whole.set(seg[l], at);
      at += seg[l].length;
    }
    backend.writeFile(`${dir}/lane${l}.wav`, floatWav(whole, c.sampleRate ?? 48000));
  }
  backend.writeFile(`${dir}/midi-out.json`, bytes(stableJson(midi.map((m) => ({ ...m, data: Array.from(m.data) })))));
  return dir;
}

async function drain(stream: ByteStream | null, sink: Uint8Array[]): Promise<void> {
  if (!stream) return;
  const reader = stream.getReader();
  for (;;) {
    const { done, value } = await reader.read();
    if (done) break;
    if (value) sink.push(value);
  }
}

/** Run case `name` alone in a fresh host process and return its digest, so a recording can prove a
 *  case's hashes do not depend on the cases before it. */
async function runAlone(rig: Rig, name: string): Promise<CaseDigest> {
  __rp_keepAlive(); // the child outlasts the host's bounded pump
  const emit = `${__CONFIG_DIR__}/parity-alone.json`;
  rig.session.backend.deleteFile(emit);
  const child = tjs.spawn([tjs.exePath, __SELF_BUNDLE__], {
    env: { ...env, RP_PARITY_UPDATE: "", RP_PARITY_ONLY: name, RP_PARITY_EMIT: emit },
    stdout: "pipe",
    stderr: "pipe",
  });
  const chunks: Uint8Array[] = [];
  const [, , status] = await Promise.all([drain(child.stdout, chunks), drain(child.stderr, chunks), child.wait()]);
  const written = rig.session.backend.readFile(emit);
  if (status.exit_status !== 0 || !written) {
    const output = chunks.map((c) => text.decode(c)).join("");
    throw new Error(`running ${name} alone failed (exit ${status.exit_status}):\n${output}`);
  }
  return JSON.parse(text.decode(written)) as CaseDigest;
}

export function runGroup(group: string, cases: ParityCase[]): void {
  const names = new Set<string>();
  for (const c of cases) {
    if (names.has(c.name)) throw new Error(`case "${c.name}" is listed twice in ${group}`);
    names.add(c.name);
  }
  if (ONLY && !names.has(ONLY)) throw new Error(`RP_PARITY_ONLY=${ONLY}: no such case in ${group}`);

  const rig = new Rig();
  const file = `${__PARITY_DIR__}/baseline/${group}.json`;
  const host = rig.audio.buildTarget();
  const raw = rig.session.backend.readFile(file);
  const baseline: Baseline | null = raw ? (JSON.parse(text.decode(raw)) as Baseline) : null;
  const target = baseline?.target ?? host;
  const onTarget = target === host;
  const missing = (c: ParityCase) => (c.needs ?? []).find((p) => !rig.session.backend.fileExists(p));

  // The child of a recording: run the one case and hand back its digest, nothing else.
  if (EMIT) {
    test(`${ONLY} (alone)`, () => {
      const c = cases.find((x) => x.name === ONLY)!;
      rig.session.backend.writeFile(EMIT, bytes(JSON.stringify(runCase(rig, c, false).digest)));
    });
    return;
  }

  const recorded: Record<string, CaseDigest> = {};
  let failed = 0;
  const selected = cases.filter((c) => !ONLY || c.name === ONLY);

  for (const c of selected) {
    const label = UPDATE ? `${c.name} (recording)` : onTarget ? c.name : `${c.name} (deterministic here; audio baseline is ${target})`;
    test(label, async () => {
      const absent = missing(c);
      if (absent) skip(`needs ${absent}`);
      try {
        if (UPDATE) {
          if (!onTarget) throw new Error(`the baseline was recorded on ${target}; this host is ${host}, so it cannot re-record it`);
          const { digest } = runCase(rig, c, false);
          const silent = c.audible.filter((l) => !laneSounds(digest, l));
          if (silent.length) throw new Error(`lane(s) ${silent.join(", ")} never sound: refusing to record silence`);
          // A stimulus the systems ignore (MIDI sent before a cart finished booting, say) would record
          // nothing but the boot.
          const stimulated = c.segments.some((s) => s.midi?.length || s.controller?.length || s.transport?.length);
          if (stimulated && compareDigests(digest, runCase(rig, c, false, true).digest, { audio: true }).length === 0)
            throw new Error("its MIDI, controller traffic and transport change nothing: refusing to record a stimulus no system hears");
          if (!ONLY) {
            const alone = await runAlone(rig, c.name);
            const differs = compareDigests(digest, alone, { audio: true });
            if (differs.length) throw new Error(`differs when run alone, so it depends on the cases before it:\n${differs.join("\n")}`);
          }
          recorded[c.name] = digest;
          return;
        }

        const expected = baseline?.cases[c.name];
        if (!expected) throw new Error(`no baseline entry: record it with RP_PARITY_UPDATE=1 pnpm test:native parity/${group}`);
        const run = runCase(rig, c, DUMP !== "");
        const problems = onTarget ? compareDigests(expected, run.digest, { audio: true }) : [];
        if (!onTarget) {
          problems.push(...compareDigests(expected, run.digest, { audio: false }));
          problems.push(...compareAudio(run.digest, runCase(rig, c, false).digest).map((p) => `not deterministic here: ${p}`));
        }
        if (problems.length) {
          const where = DUMP ? `\nlanes and MIDI out written to ${dump(rig, group, c, run.lanes, run.midi)}` : "";
          throw new Error(problems.join("\n") + where);
        }
      } catch (e) {
        failed++;
        throw e;
      }
    });
  }

  // Last: write the recording, or check the baseline holds no case the table has dropped.
  test(UPDATE ? `${group}: write the baseline` : `${group}: the baseline holds only these cases`, () => {
    if (UPDATE) {
      if (failed) throw new Error(`${failed} case(s) failed, so nothing was written`);
      // A filtered recording replaces only its case. An unfiltered one drops entries for cases no longer in
      // the table, but a case skipped for a missing fixture keeps the entry it had.
      const kept: Record<string, CaseDigest> = ONLY ? { ...(baseline?.cases ?? {}) } : {};
      if (!ONLY) for (const n of names) if (!(n in recorded) && baseline?.cases[n]) kept[n] = baseline.cases[n];
      Object.assign(kept, recorded);
      expect(rig.session.backend.writeFile(file, bytes(stableJson({ target: host, cases: kept })))).toBeTruthy();
      return;
    }
    if (ONLY || !baseline) return;
    const stale = Object.keys(baseline.cases).filter((n) => !names.has(n));
    expect(stale.length === 0, `entries for cases no longer in the table (re-record to drop them): ${stale.join(", ")}`).toBeTruthy();
  });
}
```

// Block partitioning: the same scene in every host block size, at both common sample rates. Output
// depends on the partition (SameBoy drops what a block overproduces, Mesen carries its resampler
// leftovers), so each size is its own baseline, and MIDI lands inside blocks rather than on their edges.
// One file per system (blocks-<system>.test.ts), so no one file outweighs the rest of test:native.
import type { ParityCase } from "./group";
import { cycle, even } from "./rig";
import { frames, mgb, MGB_CHANNELS, BOOT_MS, NES_CHANNELS, phrase, ROMS, smsggdj, smsStart, type Blocks } from "./scenes";

const RATES = [44100, 48000];
const SPLITS: [string, Blocks][] = [
  ["64", (n) => even(n, 64)],
  ["199", (n) => even(n, 199)],
  ["512", (n) => even(n, 512)],
  ["1024", (n) => even(n, 1024)],
  ["8192", (n) => even(n, 8192)],
  ["cycle", (n) => cycle(n, [64, 199, 512, 1024, 8192, 333])],
];

export type BlockSystem = "mgb" | "nes" | "sms" | "gg";

function blockCase(system: BlockSystem, sr: number, split: string, blocks: Blocks): ParityCase {
  const base = { name: `${system}-${sr}-${split}`, sampleRate: sr, outputs: 2 as const, audible: [0, 1] };
  switch (system) {
    case "mgb":
      return {
        ...base,
        setup: (rig) => void mgb(rig),
        segments: [{ blocks: blocks(frames(sr, BOOT_MS)) }, { blocks: blocks(frames(sr, 600)), midi: phrase(sr, MGB_CHANNELS) }],
      };
    case "nes":
      return {
        ...base,
        setup: (rig) => void rig.add(ROMS.bliptoaster),
        segments: [{ blocks: blocks(frames(sr, BOOT_MS)) }, { blocks: blocks(frames(sr, 600)), midi: phrase(sr, NES_CHANNELS) }],
      };
    default:
      return {
        ...base,
        setup: (rig) => void smsggdj(rig, system, false),
        segments: [...smsStart(sr, blocks), { blocks: blocks(frames(sr, 600)) }],
      };
  }
}

export function blockCases(system: BlockSystem): ParityCase[] {
  return RATES.flatMap((sr) => SPLITS.map(([split, blocks]) => blockCase(system, sr, split, blocks)));
}

// Many systems fanned across the host's outputs (Stereo / TwoPerInstance / OnePerInstance). The order
// systems sum in, and OnePerInstance's L-then-R mono association, are what B1's wiring has to reproduce.
// One file per mode (routing-<mode>.test.ts).
import type { ParityCase } from "./group";
import { even, type Rig } from "./rig";
import { frames, mgb, mgbFile, BOOT_MS, phrase, ROMS } from "./scenes";
import type { AudioRouting } from "../../src/settingsEnums";

const SR = 48000;
const blocks = (n: number) => even(n, 512);

// Mixed cores by slot, so every count crosses the SameBoy / Mesen boundary.
const BY_SLOT: ((rig: Rig) => unknown)[] = [
  (rig) => mgb(rig),
  (rig) => rig.add(ROMS.bliptoaster),
  (rig) => mgbFile(rig),
  (rig) => rig.add(ROMS.vrc6),
  (rig) => mgbFile(rig),
];

/** The lanes MultiOutRouter feeds for `count` systems (BlockRunner.hpp). */
export function routedLanes(mode: AudioRouting, outputs: number, count: number): number[] {
  const lanes = new Set<number>();
  for (let i = 0; i < count; i++) {
    if (mode === "twoPerInstance") [(2 * i) % outputs, (2 * i + 1) % outputs].forEach((l) => lanes.add(l));
    else if (mode === "onePerInstance") lanes.add(i % outputs);
    else [0, 1].forEach((l) => lanes.add(l));
  }
  return [...lanes].sort((a, b) => a - b);
}

export function routingCases(mode: AudioRouting): ParityCase[] {
  const out: ParityCase[] = [];
  for (const outputs of [2, 4, 8] as const)
    for (const count of [1, 2, 3, 5])
      out.push({
        name: `${mode}-o${outputs}-n${count}`,
        sampleRate: SR,
        outputs,
        audible: routedLanes(mode, outputs, count),
        setup: (rig) => {
          for (let i = 0; i < count; i++) BY_SLOT[i]( rig );
          rig.project.setAudioRouting(mode);
        },
        // sendToAll: every system hears the phrase, mGB on its voices 0..3 and the NES on its channels 0..3.
        segments: [{ blocks: blocks(frames(SR, BOOT_MS)) }, { blocks: blocks(frames(SR, 600)), midi: phrase(SR, [0, 1, 2, 3]) }],
      });
  return out;
}

          instruments: [0, 0, 0, 0, 0, 0, 0, 0],

/** Add an LSDj build with `sav` as its battery and lsdj-sync set to `config`. Each system gets its own copy
 *  of the ROM, so its battery is the one written here rather than a fresh "-2.sav" slot. */
export function lsdj(rig: Rig, rom: string, sav: Uint8Array, config: Record<string, unknown>): number {
  const copy = rig.rom(rom, `s${rig.project.systems.view().length}-`);
  rig.session.backend.writeFile(copy.replace(/\.[^./]+$/, ".sav"), sav);
  const id = rig.project.systems.addSystem(copy);
  if (id == null) throw new Error(`${rom} did not build`);
  rig.project.systems.setRoleConfig(id, "lsdj-sync", config);
  return id;
}

export const boot = (): Segment => ({ blocks: blocks(frames(SR, LSDJ_BOOT_MS)) });

/** Press START on `slot` after this segment, and release it after the next (an 80 ms tap). */
export function tap(slot = 0): Segment[] {
  return [
    { blocks: blocks(frames(SR, 10)), after: (rig) => void rig.audio.pressButton(rig.id(slot), START, true) },
    { blocks: blocks(frames(SR, 80)), after: (rig) => void rig.audio.pressButton(rig.id(slot), START, false) },
  ];
}

export function lsdjCase(
  name: string,
  rom: string,
  setup: (rig: Rig) => unknown,
  segments: Segment[],
  outputs: 2 | 4 = 2,
  audible: number[] = outputs === 2 ? [0, 1] : [0, 1, 2, 3],
): ParityCase {
  return {
    name,
    needs: [rom],
    sampleRate: SR,
    outputs,
    audible,
    setup: (rig) => void setup(rig),
    segments: [boot(), ...segments],
  };
}

### The parity baseline (`test-native/parity/`)

Exact output, not levels. Every other audio test asserts RMS, peaks or timing tolerances, which a

engine and records, per case, a hash of every output lane of every segment, the kernel's MIDI out, and
each system's SRAM and work RAM at the end; one changed bit fails it. It is the gate Phase B of the
modular graph engine is held to ([docs/modular-graph-phase-b0-design.md](../docs/modular-graph-phase-b0-design.md)).

- **Cases are driven through the stores**, as the UI drives them, so they survive the engine moving
  underneath. [parity/rig.ts](../packages/retroplug/test-native/parity/rig.ts) boots the app's own control
  plane and resets it before each case; [parity/scenes.ts](../packages/retroplug/test-native/parity/scenes.ts)
  holds the systems and stimuli the groups share; each `parity/<group>.test.ts` is a table of cases.
- **Rendering goes through `renderBlocks`**, a harness-facet driver call that repeats `PluginDSP::run`'s
  order for every host block: stage MIDI at its frame, drain the command ring, apply transport,
  `processBlock` at 2/4/6/8 lanes, take the MIDI out.
- **Cores power on in a fixed state.** The runner sets `RETROPLUG_DETERMINISTIC=1` for `parity/` files
  only ([util/Determinism.hpp](../packages/native/src/util/Determinism.hpp)): SameBoy's power-on randomness
  off, Mesen NES RAM all zeros, the SMS VDP starting at scanline 0. The app keeps the random power-on.
- **Baselines** are `parity/baseline/<group>.json`, one value per line, each lane `<fnv> <rms>`, so a
  re-record diffs readably. Audio is compared exactly only on the target a baseline was recorded on
  (`linux-x64-gnu13`: the devcontainer and CI's linux-x64 job, both GCC 13.3), because float output is
  bit-stable only for one compiler on one architecture. On any other target each case renders twice and
  must agree with itself, and its MIDI out, SRAM and work RAM are still held to the baseline.
- **Re-record** with `RP_PARITY_UPDATE=1 pnpm test:native parity/<group>` (`RP_PARITY_ONLY=<case>` for one
  case). A recording is refused: off the baseline's target; for a case whose hashes change when it is
  re-run alone in a fresh process (it would depend on the cases before it); for a case whose `audible`
  lanes are silent after its first (boot) segment; and for a case whose MIDI, controller traffic and
  transport change nothing (a stimulus sent before a cart finished booting records only the boot).
  `RP_PARITY_DUMP=<dir>` writes a failing case's lanes as float WAVs and its MIDI out as JSON. An
  intentional audio change re-records the groups it moves in the same commit, and that diff is the record
  of what moved.
